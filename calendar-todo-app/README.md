# Calendar TODO App

A modern, interactive calendar-based TODO application built with React.

## Features

- **Full-screen calendar UI** as the primary interface (month & week views)
- **Smooth animated transitions** between months via Framer Motion
- **Task management** — add, edit, delete, and toggle tasks per date
- **Side panel** with full task details, progress bar
- **Dark / Light mode** toggle
- **Glassmorphism styling** with Tailwind CSS
- **LocalStorage persistence**
- **Keyboard shortcuts** (arrow keys to navigate months)
- **Fully responsive** (desktop + mobile)

## Tech Stack

- React 19 (Vite)
- Tailwind CSS 4
- Framer Motion
- date-fns
- Lucide React (icons)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
